# Binary Classification Project

A beginner-friendly machine-learning project using Logistic Regression and Random Forest to classify the built-in Breast Cancer Wisconsin dataset into two classes.

## Files
- `Binary_Classification.ipynb` — complete notebook with data exploration, training, evaluation, plots, and a sample prediction.
- `requirements.txt` — Python package dependencies.

## Run locally
```bash
python -m pip install -r requirements.txt
jupyter notebook Binary_Classification.ipynb
```

You can also upload the notebook to Google Colab and run it there.

**Disclaimer:** This project is for educational purposes only and must not be used as a medical diagnostic tool.
